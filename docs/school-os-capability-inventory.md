## Verified implementation changes

Attendance updates now enforce the same active, organization-scoped enrollment check already used by attendance creation. Focused mocked action tests distinguish valid active enrollment from inactive and missing/out-of-organization targets. This closes a source-level integrity gap; it is not proof of database RLS enforcement or a complete live attendance workflow.

Authentication UI changes add password visibility controls, password recovery request and completion screens, and a callback destination allowlist. Reset-email delivery and Supabase redirect configuration are environment-dependent and have not been verified against the auth service.

The School OS shell now exposes academic structure, classes, finance and tenant tasks only to readers with the relevant permissions. Module cards are permission-gated, and ordinary school users are no longer linked to platform-only Control Plane routes.

Task actions refresh `/school/tasks` and `/school` in addition to preserving the existing `/control/tasks` revalidation. Task action feedback uses alert/status semantics.
